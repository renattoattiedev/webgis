# Vídeo Piloto — Demonstração WebGIS RunForrestGIS

## 🎯 Objetivo
Demonstrar o fluxo completo do sistema: **publicar um shapefile de quadras no GeoServer e consumi-lo no WebGIS**, com narração em PT-BR.

## 🎬 Roteiro (video piloto, ~90s)

### Cena 1 — Abertura (0:00 - 0:12)
"Apresentamos o RunForrestGIS: a plataforma geoespacial para publicação e gestão de dados cadastrais. Nesta demonstração, vamos publicar um arquivo shapefile de quadras e visualizá-lo diretamente no mapa."

### Cena 2 — O dado (quadras) (0:12 - 0:22)
"Aqui está o dado de entrada: um shapefile com as quadras da região de Brasília, no sistema de coordenadas SIRGAS 2000 UTM zona 23S. São mais de cinco mil polígonos que representam os quarteirões cadastrais."

### Cena 3 — Publicação no GeoServer (0:22 - 0:48)
"Publicamos esta camada no GeoServer, apontando para o banco runforrest. A camada quadras foi registrada e vinculada a um estilo SLD, que define como os polígonos são desenhados: preenchimento verde com contorno escuro."

### Cena 4 — Consumo no WebGIS (0:48 - 1:20)
"Agora, no RunForrestGIS, a camada já está disponível. Navegamos no mapa, que está centrado em Brasília, e adicionamos a camada de quadras. Observe os polígonos renderizados diretamente sobre o mapa — o dado cadastral, pronto para consulta e análise."

### Cena 5 — Fechamento (1:20 - 1:30)
"Com o RunForrestGIS, publicar e consumir dados geoespaciais é rápido e integrado. Obrigado por assistir."

## 📄 Narração (texto contínuo para TTS)
Apresentamos o RunForrestGIS, a plataforma geoespacial para publicação e gestão de dados cadastrais. Nesta demonstração, vamos publicar um arquivo shapefile de quadras e visualizá-lo diretamente no mapa.

Aqui está o dado de entrada: um shapefile com as quadras da região de Brasília, no sistema de coordenadas SIRGAS 2000 UTM zona 23 Sul. São mais de cinco mil polígonos que representam os quarteirões cadastrais.

Publicamos esta camada no GeoServer, apontando para o banco runforrest. A camada quadras foi registrada e vinculada a um estilo SLD, que define como os polígonos são desenhados: preenchimento verde com contorno escuro.

Agora, no RunForrestGIS, a camada já está disponível. Navegamos no mapa, que está centrado em Brasília, e adicionamos a camada de quadras. Observe os polígonos renderizados diretamente sobre o mapa: o dado cadastral, pronto para consulta e análise.

Com o RunForrestGIS, publicar e consumir dados geoespaciais é rápido e integrado. Obrigado por assistir.
